# AIOrbit Models - Data Dictionary

This document defines the public dataset schema used in
`data/final/models_final.csv`.

| Column | Description |
|---|---|
| Model Name | Public name of the AI model |
| Model Family | Model family or generation grouping |
| Company / Provider | Primary organization/provider associated with the model |
| Official Website | First-party provider/model page when verified |
| Release Date | Model release date when available |
| Last Updated | Most recent model update date when available |
| Model Type / Task | Primary model family, modality, or task characteristics |
| Description | Concise factual model description |
| Modalities | Supported input/output modalities |
| Context Window | Maximum supported context size |
| Maximum Output | Maximum supported output size |
| Reasoning | Whether reasoning capability is supported |
| Function / Tool Calling | Whether function/tool calling is supported |
| Structured Output | Whether structured output is supported |
| Vision | Vision capability |
| Audio | Audio capability |
| Multimodal | Whether multiple modalities are supported |
| Embeddings | Verified embedding capability status |
| API / Platforms | Known API/platform access points |
| Open Source / Weights | Whether model weights are openly available |
| License | Verified license information |
| Hugging Face | Hugging Face model/repository reference |
| GitHub | GitHub repository reference |
| Documentation | Relevant documentation URLs |
| Pricing | Verified pricing information |
| Benchmarks | Benchmark evidence or references |
| Adoption / Downloads | Public adoption/download information when available |
| Quality Score | Internal curation score from 0–100 |
| Quality Band | Curation quality category |
| Last Verified | Timestamp/date associated with verification |
| Source URLs | Supporting source references |
